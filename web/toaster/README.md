# Toaster

## Installation

```console
npm i @k4k3ru/toaster
```

## Usage

1. Import the package.

```javascript
import { Toaster } from 'YOUR_PROJECT_PATH/node_modules/@k4k3ru/toaster/dist/script.js';
```

2. Toast a notification.

Toast for information.
```
Toaster.Info('INFO');
```

Toast for success.
```
Toaster.Success('SUCCESS');
```

Toast for warning.
```
Toaster.Warning('WARNING');
```

Toast for error.
```
Toaster.Error('ERROR');
```
